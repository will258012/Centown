# Centown 

English [中文](README-zh_cn.md)

## Required Minecraft Installation

* Minecraft 1.16.5
* [Fabric Loader](https://fabricmc.net/use/installer/)

## Required Mods

Please use the 1.16.5 versions of the mods listed below.

* [Biome Makeover](https://modrinth.com/mod/biome-makeover)
* [Christmas Spirit](https://www.curseforge.com/minecraft/mc-mods/christmas-spirit-rewoven)
* [Fabric API](https://modrinth.com/mod/fabric-api)
* [Fabric Simple Elevators](https://www.curseforge.com/minecraft/mc-mods/fabric-simple-elevators)
* [Joban Client Mod](https://modrinth.com/mod/jcm)
* [Minecraft Transit Railway](https://modrinth.com/mod/minecraft-transit-railway)
* [London Underground Addon](https://modrinth.com/mod/the-tube)
* [RGB Blocks](https://www.curseforge.com/minecraft/mc-mods/rgb-blocks)

## Save Installation

After cloning all the files([Download the image files here!](Image/README.md)), open `Apply-Image.cmd`. If successful, the save should appear in the `world` folder in the current directory.

Then, move it to your save folder (`saves`).

## Troubleshooting

If your railway data is not loading correctly, open `Fix-railway-data.zip` and follow the instructions inside.
